# SLC-Build-Pro

Silikon işlemciler ve karmaşık mantık devreleri tasarlamak için geliştirilmiş web tabanlı simülasyon aracı. On binlerce mantık kapısını (gate) yüksek performansla çalıştırabilir.

A web-based simulation tool developed for designing silicon processors and complex logic circuits. Capable of handling tens of thousands of logic gates with high performance.

**Canlı Uygulama / Live App:** [SLC-Build-Pro](https://github.io)

**Tarayıcı Notu / Browser Note:** Bu uygulama en iyi performans ve tam uyumluluk için özellikle Microsoft Edge ile tasarlanmıştır. / This application is specifically designed and optimized for Microsoft Edge for maximum performance and full compatibility.

## Özellikler / Features
* **Yüksek Kapasite / High Capacity:** On binlerce mantık kapısını (logic gate) gecikme olmadan işleyebilme.
* **Microsoft Edge Uyumluluğu / Microsoft Edge Optimized:** Edge tarayıcısında akıcı ve sorunsuz çalışma.
* **Kurulum Gerektirmez / No Installation:** Doğrudan tarayıcı üzerinden hızlı erişim.
* **İşlemci Tasarımı / Processor Design:** Sıfırdan kendi silikon mimarinizi ve devrelerinizi oluşturma imkanı.
